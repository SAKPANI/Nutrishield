# 🛡️ NutriShield

## 📌 À propos du projet
Ce dépôt a initialement été créé dans le cadre du **projet LAFIA** avec pour objectif de centraliser et de construire un dataset complet à partir de diverses sources de données collectées par l'équipe. 

Cependant, les données collectées sur le terrain s'étant révélées insuffisantes pour atteindre nos objectifs initiaux, le projet a stratégiquement évolué. Face à ce défi, nous avons saisi l'opportunité de concevoir une solution plus ciblée et à fort impact : **NutriShield**.

**NutriShield** est un projet né de cette transition, axé sur le développement d'un modèle de Machine Learning capable de **prédire le risque de malnutrition chez l'enfant**. 

---

## 🚀 Évolution et Approche Technique
Le dépôt ne se limite plus à la simple collecte de données, mais héberge désormais un pipeline complet d'apprentissage automatique :
* **Prétraitement & Équilibrage :** Utilisation de la technique **SMOTE** pour pallier le manque de données initiales et rééquilibrer les classes.
* **Modélisation :** Entraînement d'un algorithme robuste de **Random Forest Classifier** pour maximiser la précision des prédictions médicales.
* **Sérialisation :** Sauvegarde et déploiement du modèle final optimisé via **Joblib**.
